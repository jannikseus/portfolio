# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.0.9] - 2026-11-22

### Added

- Localized blog section with Markdown-based posts and detail pages.
- Light, dark, and system theme modes with a compact theme switcher.
- Industrial data drift detection project presentation.
- Structured project descriptions for overview, technical approach, architecture, and role.

### Changed

- Updated the professional positioning toward backend software engineering, machine learning, and infrastructure.
- Updated dependencies to their compatible patch and minor releases.

## [0.0.8] - 2026-04-06

### Added

- Mobile navigation menu with drawer behavior and Escape-key support.
- Improved keyboard and screen-reader navigation.
- Vite development tooling integration.

### Changed

- Refined responsive header and navigation behavior.
- Updated localization strings and layout configuration.

## [0.0.7] - 2026-04-05

### Added

- Expanded project presentation with structured descriptions and role information.

### Changed

- Cleaned up portfolio content and localization files.
- Updated project data and the project overview layout.
- Improved the home page presentation.

### Removed

- Removed the `/lab` route and unused experimental content.

## [0.0.6] - 2026-04-04

### Added

- Privacy policy and imprint pages for German and English locales.
- Markdown-based legal document components.
- German alias routes for the privacy and imprint pages.

### Changed

- Replaced inline legal page content with localized Markdown sources.
- Improved legal page structure and rendering.
- Updated Docker image tagging and release workflow behavior.

## [0.0.5] - 2026-04-04

### Changed

- Refined Docker image tagging for branch builds and releases.
- Fixed container image tags and release tagging logic.
- Updated deployment documentation for tagged image versions.

## [0.0.4] - 2026-04-03

### Changed

- Consolidated container build and release workflow configuration.
- Removed the previous tag-release workflow and streamlined README instructions.

## [0.0.3] - 2026-04-03

### Changed

- Iterated on container build workflow and release automation.

## [0.0.2] - 2026-04-03

### Changed

- Adjusted container build workflow configuration and release metadata.

## [0.0.1] - 2026-04-03

### Added

- Initial portfolio scaffold with SvelteKit, Bun, Tailwind, and shadcn-svelte components.
